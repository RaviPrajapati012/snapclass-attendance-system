📸 SnapClass – AI Intelligent Attendance System

An AI-powered attendance management system using Face Recognition.

📌 About the Project

SnapClass is an AI-based attendance management system that automates the traditional attendance process using face recognition technology. It helps educational institutions manage student attendance digitally, reduce manual work, and improve accuracy.

🎯 Problem Statement

Traditional attendance systems require time-consuming manual work and can lead to human errors and proxy attendance. SnapClass provides an automated solution using AI and face recognition.

✨ Features

- 🤖 AI-Based Face Recognition
- 📷 Automated Attendance Marking
- 👨‍🎓 Student Management
- 📊 Digital Attendance Records
- ☁️ Supabase Database Integration
- 🖥️ Interactive Streamlit Dashboard
- ⚡ Simple and User-Friendly Interface

🛠️ Technologies Used

- Programming Language: Python
- Frontend: Streamlit
- Database: Supabase
- AI Technology: Face Recognition
- Tools: VS Code, Git, GitHub

⚙️ Installation & Setup

Step 1: Clone the Repository

git clone https://github.com/RaviPrajapati012/snapclass-attendance-system.git

Step 2: Navigate to the Project Folder

cd SnapClass

Step 3: Create a Virtual Environment

python -m venv venv

Step 4: Activate Virtual Environment

venv\Scripts\activate

Step 5: Install Required Dependencies

pip install -r requirements.txt

Step 6: Run the Application

streamlit run app.py

🔐 Environment Configuration

Configure your Supabase credentials securely before running the application.

Never upload API secrets, passwords, or private keys to GitHub.
